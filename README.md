# Linux Users, Groups, and Permissions

A practical Ubuntu Server lab demonstrating basic Linux user and permission
administration through a small creative studio scenario.

## Scenario

A small creative studio needs separate access for its design team and finance
administrator. The lab will create user accounts, organize them into groups,
and configure shared and restricted directories.

## Project goals

- Create and manage Linux users and groups.
- Assign directory ownership and permissions.
- Verify access using different user accounts.
- Document the process with explanations and screenshots.

## Environment

- Operating system: Ubuntu Server
- VM hostname: `ubuntu-lab`
- Initial administrator account: `labadmin`

## Project phases

1. Prepare the virtual machine and document the environment.
2. Create users and groups for the studio scenario.
3. Configure directory ownership and permissions.
4. Verify allowed and denied access.
5. Review the documentation and screenshots.
